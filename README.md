# ArcheTypist
Classify scRNA-seq samples into archetypes based on cell composition

## Installation

For now, the package needs to be installed from GitHub (run time <5 minutes):

```bash
git clone https://github.com/Teichlab/ArcheTypist
cd ArcheTypist
pip install .
```

## Usage and Documentation

Please refer to [ReadTheDocs](https://archetypist.readthedocs.io/en/latest/)
